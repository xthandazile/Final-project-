# Final-project :Chef Menu App
Project Description 
The Chef Menu Manager App is a React native mobile application developed to help chefs manage their restaurant menus.It allows users to add,view,edit,update,search,filter and delete menu item

The application provides a simple and user-friendly interface to make menu management easier and more efficient.

2. Technologies Used

- React Native
- JavaScript
- Expo Snack
- React Hooks ("useState")
- React Native Picker
- React Native Components

3. Application Features

3.1 Home Screen

The Home Screen displays all prepared menu items. It allows users to view and manage their dishes.

3.2 Add Menu Item

Users can add new dishes by entering:

- Dish name
- Dish description
- Course type
- Price

3.3 Created dropdown list

- Starter
- Main Course
- Dessert

 3.4 Users can edit existing menu items.

- Select the Edit button on a dish.
- Update the dish information.
- Click Update Menu Item to save the changes.
